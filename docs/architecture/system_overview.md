# System Architecture Overview

## Overview
RosyClass is a comprehensive management system for English centers. It combines CMS (Content Management System) for the public website, CRM (Customer Relationship Management) for sales/leads, and LMS (Learning Management System) for academic tracking.

## Technology Stack
- **Frontend/Backend**: Next.js (App Router)
- **Styling**: Tailwind CSS, Shadcn UI
- **Database**: PostgreSQL
- **ORM**: Prisma
- **Authentication**: NextAuth.js

## Core Modules
1. **Dashboard**: High-level KPIs and metrics.
2. **Website CMS**: Dynamic content management.
3. **Lead CRM**: Pipeline management for prospective students.
4. **Student Management**: Profiles, tracking, and history.
5. **Course & Class Management**: Academic offerings and logistics.
6. **Schedule & Attendance**: Recurring schedules and daily tracking.
7. **Payments**: Invoicing and payment tracking.
8. **Portals**: Role-specific views.

## User Roles
- Super Admin
- Admin
- Consultant
- Accountant
- Teacher
- Student / Parent
